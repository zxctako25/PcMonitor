# PcMonitor

A lightweight and minimalist utility for real-time PC resource monitoring and hardware system specifications tracking.

## Features

* **Real-Time Monitoring:** Live tracking of CPU, GPU, and RAM usage with clear visual indicators.
* **Thermal Statistics:** GPU temperature monitoring in real time.
* **Hardware Details:** Displays key system component specifications:
  * CPU model
  * GPU model and allocated VRAM usage
  * Total and currently used RAM capacity
  * Motherboard model
  * Operating System details
* **Clean UI:** Modern dark-themed interface built in the Windows 11 / Fluent style.

## System Requirements

* Operating System: Windows 10 / 11

## Quick Start

### Installation & Execution

1. Clone the repository:
   ```bash
   git clone https://github.com/zxctako25/PcMonitor.git
   cd PcMonitor
   ```

2. Downaload Qt6 Creator and needed tools
   ```qt6
   open project, and build it by CMake
   ```
   
2. Run the executable from the build directory:
   ```bash
   ./PcMonitor.exe
   ```
